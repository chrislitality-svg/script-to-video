# 踩坑清单（按代价排序，出问题先查这里）

## 流程级

| 坑 | 现象 | 解法 |
|---|---|---|
| 换配音后时长漂移 | 新 TTS 每句 ±0.5s，场景边界全变、动作错拍 | sync.py 自动重排；场景内 VO 对齐动作按新旧时长比例脚本化缩放 |
| 静默空文件 | ffmpeg 对缺失/空音频返回空但退出码 0，混音无声 | load 后 `assert len(w)>0` |
| 先写动画后配音 | 动作时刻与语音错拍，返工 | 先配音量时长，再排 timeline，再写动画 |
| 审计器自身有 bug | 时间采样漂移漏审末段 | 审计器也要被审计：喂已知坏例验证能抓到 |
| 机械字幕分块 | "真不是。"被并进长句 | vo_lines.json 手动指定 cues，sync 按字重分摊时间 |

## 审计与视觉

| 坑 | 现象 | 解法 |
|---|---|---|
| 审计盲区：常驻元素 | 场景文字与图签/抬头叠压抓不到（不在 .scene 内） | 目检兜底，重点查底部右侧 |
| 碰撞误报四类 | SVG text 双计、淡出层、贴边、父子包含 | checkVisibility 含祖先透明度；>14px 才报；包含跳过；data-okov 豁免 |
| 红章压字 | 判定章盖在数字/大字上 | 章是"判定"不是装饰，压线不压字；data-okov 要克制 |
| 巨字越界 | Inter 数字 -0.02em 后仍超宽 | 审计器以墨迹盒（Range.getBoundingClientRect）为准，勿用元素盒 |
| inline-block 吃空格 | stagger 拆字后词间距消失 | 关键间距用 margin，不依赖空格 |

## 渲染与合成

| 坑 | 现象 | 解法 |
|---|---|---|
| concat 前坏段 | 无报错的偶发坏帧，拼接后错乱 | **逐段**末帧 vs 源 JPG 比对 RMS<8，坏段重编 |
| 单声道无声 | 文件里有音轨但播放器没声 | pan=stereo 显式复制；-ac 2 有 -3dB 能量补偿 |
| alimiter 异常 | 正弦被压到 1/8 | 弃用，自写峰值包络限幅 |
| loudnorm 够不着 | 被天花板卡住差 2dB | 两遍法：第一遍测参数，第二遍带 measured |
| AAC 过冲 | TP 超 0dBFS 破音 | 限幅天花板 -3dBFS + 合成 volume=0.9 |
| PIL 渲染慢 | 全分辨率辉光模糊拖死 | 整体迁移浏览器渲染（SVG/CSS 滤镜免费） |

## TTS 与环境

| 坑 | 现象 | 解法 |
|---|---|---|
| 在线 TTS 空响应 | NoAudioReceived 偶发 | 重试 4 次 + 已存在跳过（断点续跑） |
| torchaudio 错配 | WinError 127 加载 dll 失败 | torch/torchaudio 版本对齐（同一 +cuXXX） |
| 数字误读 | "2022"读成"二千二十二" | 年份逐字转写、小数点转"点"，写在 tts_text() |
| 音乐抢戏 | 配乐盖过人声 | RMS 归一 -23dB + ducking -8dB；母带过的曲目要压更低 |

## 设计判断（最容易犯的三个）

1. **都是图片拼接=幻灯片**——必须有持续运动的图形语言，风格即叙事。
2. **信息贪多**——每场景只承载一个信息点；每数字只讲一次，放情绪峰值。
3. **音效抢戏**——音效是标点不是背景；密度砍半再砍半，听众不会觉得少。
