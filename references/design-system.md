# 视觉系统规范（蓝图 × 瑞士数据叙事）

题材与形式强绑定才立得住：工程=图纸，中医=本草图谱，考古=地层剖面，AI=流水线图纸。
换题材时重做的是：事实清单、文案、场景图形语言、配色与图签内容；可迁移的是整套纪律。

## 一、色彩纪律（全片 ≤5 色）

| 角色 | 色值 | 用途 |
|---|---|---|
| 底 | `#0E2843` 深蓝 + 中心提光 | 唯一背景 |
| 主线 | `#E9F2FB` 蓝白 | 图形主线、结构线 |
| 辅线 | `#8FB3D4` / `#5D82A6` | 次级标注、虚线、弱元素 |
| 强调 | `#FFC24B` 琥珀 | 关键数字、当前动作、发光 |
| 印章 | `#FF6157` 红 | **只**在"判定"时刻出现（淘汰✕/验收章） |

- 红色纪律：红 = 判定。全片红色出现次数 = 判定次数，绝不做装饰。
- 强调纪律：琥珀只给关键数据与当前动作，不给标题。
- 防跑色：抽样帧必须满足 B>G>R（见 templates/check.py）。

## 二、字体与字号三级制

- 中文 MiSans（或思源黑体），西文与数字 Inter（OFL 授权）。
- 大标题字重 600（不用 900 堆重），大数字 Inter 700，数字 `-0.02em` 收紧，
  小标签放宽 `0.08–0.3em`。
- 三级制，砍掉中间档：
  - 巨数字 150–260px（一屏一个）
  - 陈述句 44–92px
  - 标签/注释 14–22px

## 三、图面语法（"这是一张图纸"的物理存在）

- **网格底**：24px 细格 + 120px 主格，四角对版标记，内框线。
- **常驻图签**（右下角标题栏）：图名随场景自动更换；
  **制图人一栏写叙事主体**（"你"/"AI"）——把叙事钉进视觉系统。
- **抬头**（左上）：项目名 + 英文副题；右上：图号 SHT XX / 总数。
- **维界线**：带箭头的尺寸标注 + 桩号式刻度，用于"测量感"。
- **图层填充**：斜线阴影/点阵 pattern 表达材质，蓝图感来自制图约定而非贴图。
- **红章**：SVG rect+text，套 `feTurbulence + feDisplacementMap` 印泥侵蚀滤镜，
  盖章 = 判定（缩放 2→1 + 旋转 -12°→0 + 屏震）。

## 四、构图安全区

- 画框 inset 22px；文字安全区左右 ≥8px、上下 ≥6px（审计器阈值）。
- 常驻元素占位：抬头 y<90；图签右下 x>742, y>1140；字幕带 y 1290–1400。
- 主体内容放 y 150–1100；**底部右侧是审计盲区**（场景文字 × 图签抓不到），目检重点。
- 巨字砸落的落点=画面重心；标注引线从主体向外呈对角线动线。

## 五、AI 出图纪律（如果需要位图）

- prompt 强制 "Absolutely no text/letters/numbers"——图内无字，字全部由代码排版。
- AI 图只做"钉在图纸上的参考照片"：CSS 滤镜链 `grayscale→sepia→hue-rotate(168°)`
  蓝双色调 + 图钉 + 图注，风格并入蓝图系统。
