# 动效语言清单

原则：每个场景至少两层运动（主动作 + 持续层）；摄像机永远 1.4%–3% 缓推；
"风格即叙事"——动画语言必须能说出"这是在制图/制造/验证"。

全部实现为 render(t,d) 纯函数内的状态计算，禁止 CSS animation / setTimeout。

## 一、基础工具（骨架已内置）

| 工具 | 公式 | 用途 |
|---|---|---|
| `ph(t,a,b)` | clamp((t-a)/(b-a)) | 时间窗归一 |
| `eo/ei` | cubic out / smoothstep | 缓动 |
| `back(u,k=1.7~2.2)` | 过冲回弹 | 砸落、弹出 |
| `shake(t,t0,amp)` | `sin((t-t0)*46)*exp(-(t-t0)*7)*amp` | 落地震屏（配 thud 音效） |
| `setDraw(e,u)` | pathLength=1 + dashoffset | SVG 线条"被画出来" |
| `march(e,t,speed)` | dashoffset=-t*speed | 虚线行进（传送带/路面） |
| `seal()` | inkrot 滤镜 + rotate+scale+shake | 红章判定 |

## 二、入场语言

| 名称 | 三拍结构 | 用在 |
|---|---|---|
| **投影先行** | 阴影摊开(0.4s) → 主体砸落(shake) → 阴影收实 | 卡片、按钮、任何"放下"的东西 |
| **绘制生长** | pathLength 描画 0.4–1.2s，可错峰多笔 | 线框、图表、地图路径 |
| **砸落 + 计数** | scale 1.9→1 back(2.2) + 数字滚动 + shake | 巨大数字 |
| **逐字 stagger** | .ch 拆字，每字 delay 70–90ms，back 弹入 | ≤6 字的大标语 |
| **引线先行** | 标注线先生长，数据后 0.3s 砸落 | 数据标注 |
| **滑落出货** | 物体从"生产线末端"滑到展示位 | 流水线产物 |

## 三、持续语言（防静帧）

| 名称 | 实现 | 用在 |
|---|---|---|
| 缓推 | 每 render 尾部 `scale(1.014+0.018*eop) ± translateY` | 全场景（骨架内置） |
| 虚线行进 | march() | 传送带、路面、流程 |
| 呼吸 | `0.55+0.45*sin(t*w)` 作用于 opacity/scale | 背景装饰、按钮 glow |
| 脉冲环 | `r=r0+34*p; opacity=(1-p)*.4`，1.4s 相位循环 | 播放键、强调点 |
| 漂浮 | `sin(t*1.1)*5 + sin(t*.7)*4 + sin(t*.5)*.5°` | 纸张、悬浮物 |
| 计数滚动 | `textContent=fmt(v*eo(u))` + 定格 stamp | 数字、统计 |

## 四、叙事语言（信息与动作绑定）

- **数字必须"有事发生"**：29.7km 配路线绘制；1414 片配逐行盖章；字数配同步计数。
- **联动反馈**：工件流过点亮工位 → 工位放大 3.5% + 描边加粗 + 工件变琥珀。
- **吞料脉冲**：漏斗/管道每"吃进"一个输入，颈部短促加粗。
- **倒计数**：结论数字从大数滚到目标（6→0），入场即悬念。
- **先出后进**：旧元素退场（0.35–0.5s）+ 0.15s 空档，再进新元素。

## 五、转场

- **扫描线**：场景前 0.55s，琥珀竖线 + 辉光拖尾从左到右扫过（骨架内置 #scan）。
- **循环收口**：末帧=首帧（纯网格+图签）。任何"看起来是常量、实际随时间变化"的
  元素（图签图名等）在最后 0.05s 静默切回首帧状态——否则循环点跳变。

## 六、声音同步约定

砸落/盖章的时刻必须与混音脚本里的 thud 对齐（误差 <0.1s）：
动画时刻改了，`shots/timeline.json` 里的 fx 时刻同步改。音效只做重音，
每场景 ≤2 个；拒绝 whoosh 铺底、拒绝 tick 雨——音效是标点，不是背景。

## 七、和通用代码视频的关系

本仓库的动作已经锁在 `render(t, d)` 上：给定时间，画面唯一。GSAP 可跳转的时间轴、Remotion「帧号的函数」是同一条原则的另外两种写法，不是要迁过去的框架。五步、拆文件的时机和确定性禁令见 references/pipeline.md。

拆参考片或复查自己的成片时，用相邻帧差分做一张运动热力图，看哪些区域真的在动。一个节拍即使只有大约一秒，冷区也要补本节的持续层，不能只靠一次入场。做法见 references/qa.md。
