# 成片复查

模型看不到 mp4 里的运动。不要靠「看完视频」改片子。抽静帧，对照代码改，再重拍那一段。原则来自宝玉文（<https://x.com/dotey/status/2105181393638531536>）。复查时换一个没写过这片的 agent、以及笔记的四格，来自花叔文（<https://x.com/AlchainHust/status/2107347834668224687>）。

已有的门不要跳：浏览器里 `auditText()` 和 `auditOverlap()` 归零，然后 `python templates/check.py` 七项全过。这一页补它们抓不到的跳变和「丑」。

## 静帧

每个场景至少两张：内容峰值一张，场景边界前后各一帧。看文字裁切、构图空洞、跑色、图形是否还在安全区（design-system.md）。硬伤改 `render(t, d)`，不改审计阈值。

运动热力图用已经截好的 JPG，不要新写一套渲染：

1. 读 `out/frames_*` 里相邻两帧，转成灰度。
2. 做绝对差分，再在时间上平均。亮的区域是在动的，暗的是静止的。
3. 一整拍（哪怕大约一秒）都是暗的，回到 motion.md 补持续层：虚线行进、呼吸、缓推、计数，至少留一层。

跳切：相邻采样帧差异突然很大，且分镜里没有「由动作带出的切」（pipeline.md），就是跳。修的是状态插值，让位置、透明度、表情缓过去，不要在两帧之间换一套不相干的 DOM。

## 换一个没写过这片的 agent

程序检查和静帧过了之后，另开一个没有参与制作的 agent。只给它成片或静帧。它只列问题，不改文件。制作方按清单改代码，再抽一轮静帧。它若开始重写场景，停掉，问题清单留下。

## 实践笔记

做对的事情记一条，换题材、换风格时还用得上。四格缺一就不记：

- 做什么
- 证据：静帧路径、帧差、对应的那句口播
- 为什么
- 何时用

写在该项目的 `shots/notes.md`。不要写进本 skill 仓库，除非这条对所有片子都成立。

## 限度

- 过曝。亮底风格（白板、Vox、发布会 UI）容易整帧发白。宝玉文把过曝列为代码视频的限度。峰值帧若高光粘成一片，降底色，不要靠滤镜硬救。
- 费用是真的。宝玉文写 Opus 5.5 的 API 价格为输入每百万 token 4 美元、输出每百万 token 20 美元，并写一条约 3 分钟的旁白短片大约用掉一周 Claude 额度的 7%。这是该文的数字（<https://x.com/dotey/status/2105181393638531536>），本仓库没有复核，不要当成当前价目，也不要为了省 token 跳过静帧复查。
- 口味。程序归零之后，好不好看仍要人看。不要替用户宣布成片好看。

## 代码视频不是底子的时候

照片级人脸和动物不要用本管线硬画。生成式模型可以做插入，宝玉文点名 Seedance、Kling、Runway Aleph。生成之后用 ffmpeg 拆成静帧，再按时间轴贴进 HTML（pipeline.md 的禁令）。比较轴是：文字准不准、局部改不改得动、旁白能不能卡到帧、同一输入能不能再渲染出同一片；对面是照片级真实感。插入不是换掉 `setTime`。

HyperFrames 和 Remotion 的取舍见 pipeline.md。这里不迁移。
