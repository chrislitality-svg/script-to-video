# 风格目录

公开来源，不是用户的 X 收藏。收藏帖尚未读到（账号需重新登录），以后可以按同样的列追加，不要把没看见的帖子写进来。

收录条件：名字和路径都在 2026-10-08 拉到的文件里。lemo-opuscar 的 43 条来自 `styleboard/catalog.json` 与 `styles/README.md`（该 README 写明由 `styles/*/style.json` 生成）。每条上游提示词在 `styles/<slug>/STYLE.md`，这里只写一句外观，不抄提示词。

`blueprint` 的执行规范以本技能原仓库 `references/design-system.md` 为准（深蓝 `#0E2843`、蓝白 `#E9F2FB`、琥珀 `#FFC24B`、红 `#FF6157` 只用于判定，抽样帧 B>G>R）。lemo-opuscar 也有同名文件夹 `styles/blueprint/`，算同一 id 的相关样片，不另起一个名字。色检冲突时以本仓库 design-system 为准。

问询时不要贴整张表。按题材从这里挑 4–6 个真实 id，再加「混搭」和「你来定」。题材不是工程时，不要把 `blueprint` 放进首推，除非用户自己提到图纸、工程、蓝图。
